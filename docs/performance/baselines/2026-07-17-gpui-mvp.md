发布候选通过交互 Session 1 的仅登录用户计划任务启动，避免 SSH Session 0 无法创建 DirectX renderer。启动计时起点位于交互 Session 内、紧邻 `Start-Process`；终点为 GPUI 完成首帧后下一帧写出的标记。每轮都枚举到一个可见主窗口。

空闲采样预热 10 秒、按固定墙钟节拍观察 60 秒，每秒重新发现进程树并按 PID 计算 CPU 增量。60 个样本的 `ElapsedSeconds` 从 1.025 到 60.007，最终发布候选始终为单进程。首个样本的短命子进程枚举返回空集合，采样器显式回退到仍存活的根进程并记录 `ProcessTreeFallback=True`；其余 59 个样本均为 `False`。

生产生命周期实测：主窗口创建 480.47 ms 且默认不可见；二次实例 178.10 ms 内退出并激活主窗口；关闭窗口 14.98 ms 内隐藏；托盘双击 118.92 ms 内恢复；托盘菜单退出成功。以上为操作响应基线，不设置 MVP 门槛。
